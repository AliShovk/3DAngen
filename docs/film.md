# Движения камеры в экшене — шпаргалка и наш риг

Собрано из общей теории (StudioBinder «Types of Camera Movements», Adobe, Backstage) и практики экшен-кино: «Борн», «Джон Уик», «Безумный Макс», «Миссия невыполнима».

## 1. Базовые движения и зачем они в экшене

| Движение | Что делает | Экшен-применение | Фильм-пример |
|---|---|---|---|
| **Push in** (наезд) | камера физически едет к объекту | напряжение перед ударом, «щелчок» решения | «Джон Уик» — наезды перед перестрелкой |
| **Pull out** (отъезд) | отъезд от объекта | показать масштаб угрозы, одиночество героя | финалы «Борна» |
| **Pan** (панорама) | поворот по горизонтали | быстрый перевод внимания | «Борн» — панорамы на бегу |
| **Whip pan** (мах) | панорама с огромной скоростью | склейка «из ниоткуда», эффект удара | «Борн: Ультиматум», «Миссия» |
| **Tilt** | поворот по вертикали | масштаб, «взгляд вверх» на угрозу | «Макс» — виды пустоши |
| **Zoom / Snap zoom** | изменение фокусного | резкий акцент, «прилипание» к деталям | «Джон Уик» — снап-зумы на оружии |
| **Dolly zoom (Vertigo)** | едешь к объекту + зум в обратную | дезориентация, шок, «земля уходит» | «Челюсти», «Гудфеллас», «Миссия» |
| **Roll / Dutch angle** | наклон камеры по оси | хаос, тревога, драка | «Борн», «300 спартанцев» |
| **Tracking / Follow** | камера идёт за героем | непрерывность погони | «Борн», «Миссия» |
| **Arc** | облёт по дуге вокруг героя | показать героя в центре событий | «Матрица», «Джон Уик 4» |
| **Boom / Crane** | вертикальный подъём/спуск | открыть пространство, финальный отъезд | «Макс: Дорога ярости» |
| **Handheld** | живая, дрожащая камера | документальность, адреналин | «Борн» (Грингласс) |
| **Bird's eye / top-down** | строго сверху | «бог смотрит», геометрия боя | «Джон Уик» — вид сверху в клубе |

## 2. Что отличает именно экшен-съёмку

1. **Смена энергии, а не постоянный экшен.** Спокойный широкий план → резкий рывок камеры. Контраст даёт удар.
2. **Мотив камеры.** Камера двигается потому, что герой что-то делает (бежит, бьёт, зажигает), а не «просто красиво».
3. **Монтаж на движении.** Склейка внутри движения (whip pan, проезд за колонну), чтобы кадр «не останавливался».
4. **Слои глубины.** Передний план (стол, пар), средний (герой), дальний (кухня) — движение читается по параллаксу.
5. **Один герой в кадре.** Центральная композиция (Миллер/«Макс») — зритель не ищет, куда смотреть.
6. **Короткие шоты.** 0.6–1.5 с на движение в кульминации, 2–4 с на «дыхание».
7. **Скорость важнее плавности.** Whip pan и crash zoom намеренно «рвут» плавность.

## 3. Наш риг (src/table/index.html → `SHOTS`)

Каждый шот — функция `cam(u, hero)`, где `u` — прогресс 0..1 внутри шота. Возвращает `az, pol, rad, tx/ty/tz, fov, roll, shake`.

```
crane down    1.30 c   pol .52→1.26, rad 9.2→6.2      открытие кухни, находим героя
push in       1.00 c   rad 6.2→3.3,   fov 38→31       напряжение перед чирканьем
whip pan      0.75 c   az -0.35→1.55, shake .004      слежка «на махе»
low arc       1.10 c   az 1.55→2.75,  pol 1.42        низкий облёт героя
crash zoom    0.85 c   fov 44→15 за 0.27 c            удар: искра
dolly zoom    1.10 c   rad 5.4→2.5 + fov 20→54        «вертиго» на вспышке
dutch handheld 1.20 c  roll .10→.26, shake .012       хаос
crane up      1.30 c   pol 1.44→.38, rad 4.2→9.4      финальный отъезд
```

Дрожание — сумма трёх несинхронизированных синусов (`nz`) на позицию/угол/крен, амплитуда `shake`.

## 4. Как снимать следующий фильм

1. Раскадровка: список шотов с длительностями (0.7–1.5 с в кульминации).
2. Добавить шот в `SHOTS` (или поправить существующий), проверить `?film=1` в браузере.
3. Покадровый рендер: `python tools/film_capture.py --frames N --fps 24`.
4. Сборка: `ffmpeg -framerate 24 -i f_%04d.png -c:v libx264 -crf 17 -pix_fmt yuv420p`.
5. Кадр 2.39:1 включается классом `body.film` (чёрные полосы сверху/снизу).
